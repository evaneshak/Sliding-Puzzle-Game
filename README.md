# Sliding Puzzle Game

A 4×4 sliding puzzle built with HTML5, CSS3, and vanilla JavaScript. It has 15 numbered image tiles and one empty square.

## Run

Open `index.html` in Google Chrome. No installation or server is needed.

## Play

Click a tile directly above, below, left, or right of the empty square. Put tiles 1 through 15 in order. **New Game** starts a scrambled, solvable puzzle. **Simple Game** starts one move from a win. The move counter tracks valid moves, and the timer tracks elapsed seconds. When you solve the puzzle, choose whether to start another game.

## Features

- Fifteen image tiles and one empty square
- Legal tile movement and solvable new games
- One-move Simple Game
- Move counter, timer, win message, and replay confirmation
- Responsive layout

The included `images/puzzle.png` is a numbered fallback image. The instructor-provided image was not available in the workspace.
